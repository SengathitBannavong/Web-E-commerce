# Web-E-commerce
This is repo to build Web E-commerce for subject web technologies and e-Services (IT4409) with 3 contribute

## Server Run
### Require
- Node JS and Docker or Podman
### Build
to build and install module and library
```bash
  npm install
```
build and start contrainer
```bash
  docker-compose up -d
```
### Run
normal run
```bash
  npm run start
```
deverlop run
```bash
  npm run dev
```
**remember to init .env file**
